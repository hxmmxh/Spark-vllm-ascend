# x86_64 + Ascend950PR_957b deployment

[中文](x86-950pr.md) | **English** · [Requirements](README.en.md)

Test environment: Ubuntu 24.04.4, GCC 13.3, Python 3.12.3, driver 25.7.rc1.2. Median TPOT was 2.909848 ms/token.

Open Bash at the repository root. Select an idle physical NPU and new work directories. uv manages Python 3.12, so no host interpreter path is needed. Keep the same terminal for subsequent steps.

```bash
set -euo pipefail
export BASE="$(pwd -P)"
export SPARK_PYTHON_VERSION=3.12
export PROFILE=x86-950pr
export REPO="$BASE/spark-deploy-$PROFILE"
export WORK="$BASE/spark-work-$PROFILE"
export DEVICE=5
export PORT=18526
export SPARK_PYPI_INDEX=https://repo.huaweicloud.com/repository/pypi/simple
export SPARK_PUBLIC_PYPI_MIRROR=1

test "$(uname -m)" = x86_64
test -f "$BASE/pyproject.toml"
test ! -e "$REPO"
test ! -e "$WORK"
uv --version
npu-smi info
```

Continue with the [shared installation, validation, and benchmark steps](common.en.md). The `x86-950pr` profile selects dependencies and the build target.
