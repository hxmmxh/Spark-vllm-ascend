# x86_64 + Ascend950PR_957b 部署

**中文** | [English](x86-950pr.en.md) · [部署要求](README.md)

测试环境：Ubuntu 24.04.4、GCC 13.3、Python 3.12.3、驱动 25.7.rc1.2。TPOT 中位数为 2.909848 ms/token。

在仓库根目录打开 Bash，选择空闲物理卡号和新的工作目录。Python 3.12 由 uv 管理，无需指定宿主机解释器路径。以下步骤使用同一终端。

```bash
set -euo pipefail
export BASE="$(pwd -P)"
export SPARK_PYTHON_VERSION=3.12
export PROFILE=x86-950pr
export REPO="$BASE/spark-deploy-$PROFILE"
export WORK="$BASE/spark-work-$PROFILE"
export DEVICE=5
export PORT=18526
export SPARK_PYPI_INDEX=https://repo.huaweicloud.com/repository/pypi/simple
export SPARK_PUBLIC_PYPI_MIRROR=1

test "$(uname -m)" = x86_64
test -f "$BASE/pyproject.toml"
test ! -e "$REPO"
test ! -e "$WORK"
uv --version
npu-smi info
```

继续执行[公共安装、验证和测试步骤](common.md)。依赖与编译目标由 `x86-950pr` 配置选择。
