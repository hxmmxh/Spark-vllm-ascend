# ARM64 + Ascend950DT_9581 deployment

[中文](arm64-950dt.md) | **English** · [Requirements](README.en.md)

Test environment: openEuler 24.03 SP4, GCC 12.3.1, Python 3.12.15, driver 25.6.rc1. Median TPOT on 2026-10-30 was 2.963747 ms/token.

Open Bash at the repository root. Select an idle physical NPU and new work directories. uv manages Python 3.12, so no host interpreter path is needed. Keep the same terminal for subsequent steps.

```bash
set -euo pipefail
export BASE="$(pwd -P)"
export SPARK_PYTHON_VERSION=3.12
export PROFILE=arm64-950dt
export REPO="$BASE/spark-deploy-$PROFILE"
export WORK="$BASE/spark-work-$PROFILE"
export DEVICE=6
export PORT=18526
export SPARK_PYPI_INDEX=https://repo.huaweicloud.com/repository/pypi/simple
export SPARK_PUBLIC_PYPI_MIRROR=1

test "$(uname -m)" = aarch64
test -f "$BASE/pyproject.toml"
test ! -e "$REPO"
test ! -e "$WORK"
uv --version
npu-smi info
```

Continue with the [shared installation, validation, and benchmark steps](common.en.md). The `arm64-950dt` profile selects dependencies and the build target.
